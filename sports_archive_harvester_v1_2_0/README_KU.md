# Sports Archive Harvester v1.2.0

ئەم وەشانە بۆ کۆکردنەوەی داتای وەرزشی بە SQLite دروست کراوە، بە تایبەتی بۆ ئەوەی داتابەیسەکە خێرا، offline و تا ڕادەیەکی زۆر کم‌قەبارە بمێنێتەوە.

## دەستپێکردن

- `OPEN_CONTROL_PANEL_WINDOWS.bat` پەنێڵی CMD دەکاتەوە.
- `FULL_COLLECTION_WINDOWS.bat` یەکەم جار مێژووی یارییە نێودەوڵەتییەکانی تۆپی پێ لە 1872 بەدواوە کۆدەکاتەوە.
- `QUICK_UPDATE_WINDOWS.bat` دواتر تەنیا یارییە نوێ و گۆڕاوەکانی ساڵی هەنووکە دەپشکنێت.

Python 3.11 یان نوێتر پێویستە؛ هیچ پەکێجی دەرەکی پێویست نییە.

## ئەوەی لە CMD نیشان دەدرێت

- کام سەرچاوە دەپشکنرێت.
- کام یاری زیاد یان نوێ دەکرێتەوە.
- ناوی تیم، ئەنجام، بەروار و ناسنامەی تۆمار.
- کام تیم و یاریزان زانیارییەکانی زیاد دەکرێت.
- کام لۆگۆ یان وێنە بە شێوەی offline هەڵدەگیرێت.
- ژمارەی تۆمارە نوێ، نوێکراوە، دووبارە و هەڵەکان.
- قەبارەی SQLite و فایلەکانی وێنە.

هەموو log ـەکان لە `logs/live_sync.log` دەمێننەوە.

## سیاسەتی پاراستنی قەبارە

لە داتابەیس تەنیا زانیارییە پێویستەکان هەڵدەگیرێن:

- وەرزش، وڵات، پاڵەوانێتی و تیم.
- یاری، ئەنجام، شوێن، داوەر، گۆڵ و ئاماری سەرەکی.
- یاریزان، بەرواری لەدایکبوون، نەتەوە، شوێنی لەدایکبوون، پۆست، باڵا و کێش.
- پەیوەندی یاریزان بە تیم و ژمارەی جل، ئەگەر سەرچاوەکە هەیبێت.
- تەنیا یەک لۆگۆ بۆ هەر تیم و یەک وێنە بۆ هەر یاریزان.

ئەم شتانە بە ئەنقەست هەڵناگیرێن:

- ڤیدیۆ، دەنگ، پوستر، banner، fan-art و thumbnail ـی یاری.
- raw JSON/raw API payload.
- HTML، cache ـی ناڕێک، وێنەی دووبارە و EXIF ـی ناپێویست.
- دەقی درێژی ناساندن و زانیارییەکانی پێشاندانی وێبسایت.

وێنەکان وەک فایل لە `data/media` هەڵدەگیرێن و SQLite تەنیا relative path، SHA-256، MIME و قەبارەکەیان تۆمار دەکات. ئەمە خێراتر و کم‌قەبارەترە لە خستنە ناو BLOB و هەموو شتێک بەبێ ئینتەرنێت کار دەکات.

- سنووری لۆگۆ: 600 KB
- سنووری وێنەی یاریزان: 900 KB
- هەمان وێنە بە hash دوو جار هەڵناگیرێت.
- URL تەنیا بۆ سەرچاوە و نوێکردنەوەی داهاتوو تۆمار دەکرێت؛ پیشاندانی وێنە بە URL پێویست نییە.

## نوێکردنەوەی خێرا

`QUICK_UPDATE_WINDOWS.bat` لە ETag و Last-Modified بەکاردەهێنێت. ئەگەر فایلە سەرچاوەکە نەگۆڕابێت، پرۆژەکە بە خێرایی دەوەستێت و هیچ ڕیزێک دووبارە ناپشکنێت. ئەگەر گۆڕابێت، تەنیا ڕیزەکانی ساڵی هەنووکە دەپشکنرێن و UNIQUE KEY ڕێگری لە تۆماری دووبارە دەکات.

## داتابەیسێکی پاک لە سەرەتاوە

لە پەنێڵدا هەڵبژاردەی `Reset` هەیە. پێش پاککردنەوە، داتابەیسە کۆنەکە بە ناوی timestamp وەک backup هەڵدەگیرێت. وەشانی نوێ هیچ داتای پێش‌پڕکراوی لەگەڵ خۆیدا نییە.

## تێبینی سەرچاوە

بنەمای مێژوویی تۆپی پێی نێودەوڵەتی لە `international_results` ـە. TheSportsDB بۆ زانیاری تیم، یاریزان و وێنەکان بەکار دەهێنرێت. لە `config.json` دەتوانرێت API key و سنووری قەبارە بگۆڕدرێت.
