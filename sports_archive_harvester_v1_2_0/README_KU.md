# Sports Archive Harvester v1.2.1

ئەم وەشانە بە شێوەی **External Media + SQLite Links** دروست کراوە. هیچ لۆگۆ، وێنە، BLOB یان Base64 لە ناو SQLite هەڵناگیرێت. داتابەیس تەنیا زانیارییە تێکستییە پێویستەکان و لینکی ناوخۆی فایلەکان هەڵدەگرێت.

## دەستپێکردن

- `OPEN_CONTROL_PANEL_WINDOWS.bat` پەنێڵی CMD دەکاتەوە.
- `FULL_COLLECTION_WINDOWS.bat` یەکەم جار مێژووی یارییە نێودەوڵەتییەکانی تۆپی پێ لە 1872 بەدواوە کۆدەکاتەوە.
- `QUICK_UPDATE_WINDOWS.bat` دواتر تەنیا یارییە نوێ و گۆڕاوەکانی ساڵی هەنووکە دەپشکنێت.

Python 3.11 یان نوێتر پێویستە؛ هیچ پەکێجی دەرەکی پێویست نییە.

## شوێنی وێنەکان

وێنەکان بە تەواوی لە داتابەیس جیاوازن:

- لۆگۆی تیمەکان: `data/media/team_logos/`
- وێنەی یاریزانان: `data/media/player_photos/`

فایلەکان بە SHA-256 ناودەنرێن و بەپێی دوو پیتی سەرەتای hash لە ژێر-فۆڵدەر دابەش دەکرێن، بۆیە هەزاران فایل لە یەک فۆڵدەردا کۆنابنەوە.

## پەیوەندی داتابەیس بە فایلەکان

SQLite تەنیا ئەم زانیارییانەی فایلەکە تۆمار دەکات:

- `relative_path` ـی ناوخۆی فایل
- `mime_type`
- `byte_size`
- `sha256`
- کاتی تۆمارکردن

پەیوەندییەکان بە foreign key ـی ڕاستەقینە دروست کراون:

- `team_media.team_id -> teams.id`
- `team_media.media_file_id -> media_files.id`
- `player_media.player_id -> players.id`
- `player_media.media_file_id -> media_files.id`

هیچ `http://`، `https://`، `data:`، URL ـی پێشاندان، image bytes، BLOB یان Base64 لە خشتەکانی وێنەدا ڕێگەپێدراو نییە. بۆ پیشاندانی وێنە داتابەیس `relative_path` دەدات و پرۆژەی داهاتوو فایلەکە لەسەر دیسک دەخوێنێتەوە؛ بۆیە دوای داگرتن هیچ پێویستی بە ئینتەرنێت نییە.

## ئەوەی لە CMD نیشان دەدرێت

- کام سەرچاوە دەپشکنرێت.
- کام یاری زیاد یان نوێ دەکرێتەوە.
- ناوی تیم، ئەنجام، بەروار و ناسنامەی تۆمار.
- کام تیم و یاریزان زانیارییەکانی زیاد دەکرێت.
- شوێنی فایلە دەرەکییەکە و قەبارەی هەر لۆگۆ/وێنە.
- `sqlite_bytes=0` بۆ دڵنیابوون لەوەی وێنەکە لە ناو SQLite نییە.
- ژمارەی تۆمارە نوێ، نوێکراوە، دووبارە و هەڵەکان.
- قەبارەی SQLite و قەبارەی جیاوازی فۆڵدەری media.

هەموو log ـەکان لە `logs/live_sync.log` دەمێننەوە.

## سیاسەتی پاراستنی قەبارە

لە داتابەیس تەنیا زانیارییە پێویستەکان هەڵدەگیرێن:

- وەرزش، وڵات، پاڵەوانێتی و تیم.
- یاری، ئەنجام، شوێن، داوەر، گۆڵ و ئاماری سەرەکی.
- یاریزان، بەرواری لەدایکبوون، نەتەوە، شوێنی لەدایکبوون، پۆست، باڵا و کێش.
- پەیوەندی یاریزان بە تیم و ژمارەی جل، ئەگەر سەرچاوەکە هەیبێت.
- تەنیا یەک لۆگۆ بۆ هەر تیم و یەک وێنە بۆ هەر یاریزان.

ئەم شتانە بە ئەنقەست هەڵناگیرێن:

- ڤیدیۆ، دەنگ، پوستر، banner، fan-art و thumbnail ـی یاری.
- raw JSON/raw API payload.
- HTML، cache ـی ناڕێک و EXIF ـی ناپێویست.
- image BLOB، Base64 و remote-display URL.
- دەقی درێژی ناساندن و زانیارییە بێ‌سوودەکانی پێشاندانی وێبسایت.

- سنووری لۆگۆ: 600 KB
- سنووری وێنەی یاریزان: 900 KB
- هەمان وێنە بە SHA-256 دوو جار هەڵناگیرێت.
- فایلە دووبارەکان دەتوانن لەلایەن چەند تیم/یاریزانێکەوە بە هەمان `media_file_id` بەکاربهێنرێن.

## پشکنینی سەلامەتی media

هەڵبژاردەی Report ئەمانە پشکنین دەکات:

- `image_blob_cells = 0`
- `remote_media_paths = 0`
- فایلە ونبووەکان
- فایلە بێ‌لینکەکان
- `PRAGMA integrity_check`
- `PRAGMA foreign_key_check`

ئەگەر BLOB یان لینکی ئینتەرنێتی لە بەشی media بدۆزرێتەوە، report بە هەڵە دەوەستێت.

## Compact

Compact:

- فایلە `.tmp` ـەکان دەسڕێتەوە.
- وێنەی بێ پەیوەندی بە تیم یان یاریزان دەسڕێتەوە.
- metadata ـی بێ بەکارهێنان پاک دەکات.
- `PRAGMA optimize` و `VACUUM` جێبەجێ دەکات.

## Reset

Reset داتابەیس و تەواوی فۆڵدەری media بە یەکەوە دەگوازێتەوە بۆ:

`data/backups/reset_YYYYMMDD_HHMMSS/`

بەم شێوەیە هیچ داتابەیسێک بە فایلە وێنەکانی خۆیەوە تێکەڵ نابێت و هیچ فایلێک بە هەڵە نامێنێتەوە.

## نوێکردنەوەی خێرا

`QUICK_UPDATE_WINDOWS.bat` لە ETag و Last-Modified بەکاردەهێنێت. ئەگەر فایلە سەرچاوەکە نەگۆڕابێت، پرۆژەکە بە خێرایی دەوەستێت. ئەگەر گۆڕابێت، تەنیا ڕیزەکانی ساڵی هەنووکە دەپشکنرێن و UNIQUE KEY ڕێگری لە تۆماری دووبارە دەکات.

## تێبینی سەرچاوە

بنەمای مێژوویی تۆپی پێی نێودەوڵەتی لە `international_results` ـە. TheSportsDB بۆ زانیاری تیم، یاریزان و داگرتنی یەک لۆگۆ/وێنە بەکار دەهێنرێت. دوای داگرتن، وێنەکە فایلێکی ناوخۆیە و بۆ بینینەوەی هیچ پەیوەندییەکی ئینتەرنێتی پێویست نییە.
